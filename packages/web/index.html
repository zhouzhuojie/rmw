rm watermarks — keep control of AI-generated text

github.com/zhouzhuojie/rmw · MIT · runs in your browser

Detect and remove invisible / format Unicode (zero-width, bidi, tags, odd spaces…) from text and code you generate with AI. Nothing is uploaded.

Report

Load an example, then Detect or Clean.

    CLI (no install):

    npx --yes github:zhouzhuojie/rmw detect notes.md
npx --yes github:zhouzhuojie/rmw clean notes.md -o clean.md

    Source · Node ≥ 18
